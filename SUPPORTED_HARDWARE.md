| Manufacturer | Model / profile | Status | Notes |
|---|---|---|---|
| Deye | SUN-6K-SG05LP1-EU-SM2-P / `deye_sg05lp1_eu_sm2_p.yaml` | **validated** | Author-owned single-phase inverter; EW11 Modbus TCP gateway |

Status meanings:

- **validated**: tested by the maintainer on owned hardware.
- **community-reported**: reported working by users but not maintainer-tested.
- **untested**: supplied as a starting point; register behavior is not verified.

Only the model above is validated. Any future profile not explicitly marked validated must be treated as unverified.
